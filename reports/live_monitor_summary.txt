Краткий отчет по живому мониторингу

Модель:
models/ueba_model.json

Обучающая выборка:
data/baseline_24h_tcp.jsonl

Длительность обучающей выборки:
24.007 часа

Количество обучающих строк:
1439

Порог аномальности:
3.176267

Проверка monitor:
После обучения был запущен monitor с сохраненной моделью. За 2 минуты было
получено 13 проверок текущего состояния компьютера. Все проверки были
классифицированы как нормальные. Отношение ошибки к порогу находилось примерно
от 0.02 до 0.09.

Почему нет отдельного JSONL с живыми аномалиями:
Monitor записывает JSONL-строки только при обнаружении аномалии. Во время этой
короткой живой проверки аномалий не было, поэтому живых anomaly-событий для
записи не появилось.

Примеры обнаруженных аномалий:
Файл reports/demo_anomalies.jsonl содержит события, полученные в demo-сценарии
с добавленными отклонениями.


English version

Live monitoring summary

Model:
models/ueba_model.json

Training dataset:
data/baseline_24h_tcp.jsonl

Training dataset duration:
24.007 hours

Training samples:
1439

Anomaly threshold:
3.176267

Monitor check:
After training, monitor was started with the saved model. During a 2-minute
run, 13 checks of the current computer state were collected. All checks were
classified as normal. The error-to-threshold ratio was approximately between
0.02 and 0.09.

Why there is no separate live anomaly JSONL:
Monitor writes JSONL records only when an anomaly is detected. During this
short live check, no anomaly was detected, so there were no live anomaly events
to write.

Anomaly examples:
The file reports/demo_anomalies.jsonl contains events generated by the demo
scenario with injected deviations.
